## Selected work

- [steuer-graph](https://github.com/cardox6/steuer-graph): a German voice agent that answers tax-firm status calls from a Neo4j knowledge graph of clients, cases, documents, deadlines and income-tax law. I built it in one day at the Global AI Berlin Mini Agentic Hack in August 2026, where it took 3rd place among 18 projects.
- [aifeelnews](https://github.com/cardox6/aifeelnews): my software engineering capstone, a sentiment platform for English and German news. FastAPI, PostgreSQL and Svelte on Google Cloud (Cloud Run, Cloud SQL, BigQuery, Natural Language API), deployed with Terraform and GitHub Actions. Live at [aifeelnews-front.web.app](https://aifeelnews-front.web.app/).
- [loadup_challenge](https://github.com/cardox6/loadup_challenge): a take-home backend challenge for LoadUp's hiring process. A TypeScript API (Fastify, Prisma, PostgreSQL, Zod, Vitest) that ranks job applicants by their assessment results, with negative marking, a recency boost and a location bonus.
- Bachelor thesis (the code isn't public): I compared GPT and Claude, prompted zero- and few-shot, with fine-tuned transformers (RoBERTa and others), VADER and expert human coders on target-dependent sentiment in political news sentences, on an 803-sentence test set. None of the pre-registered comparisons between the LLM and fine-tuned setups was significant, the LLMs reached kappa 0.69–0.73 against the expert labels (close to the coders' agreement with each other, 0.72), and all LLM runs together cost $2.75.
